# Map: Livestream Virtual Sanctuary

## Notes & Decisions
- Free ($0) video streaming architecture using Facebook Live and YouTube Live responsive embeds.
- "Virtual Sanctuary" layer adds distraction-free worship, daily Gospel readings, real-time parish mass intentions, interactive candle lighting, and in-stream cashless offertory.
- Real-time candle counting tracked via `light_church_candle` RPC.
- Church Admins have a dedicated live toggle switch on their dashboard.
