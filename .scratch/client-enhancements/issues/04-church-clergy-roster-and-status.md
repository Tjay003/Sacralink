# Issue 04: Church Clergy Directory & Real-Time Status

Type: feature
Status: ready-for-agent
Blocked by: 12, 03

---

## 1. Description
Anyone visiting a parish page, including logged-out visitors, should see the priests assigned to that parish and a status.

Changes from the original draft:
- **No direct table reads.** `profiles` is readable only by logged-in users and `priest_availability.reason` (e.g. sick leave) is readable by any logged-in user. The roster comes from the ticket 12 RPC `get_parish_clergy(p_church_id)`, which returns only name, title, designation and a computed status. Leave reasons, emails and phones never reach the client.
- **Priest-to-parish rule** matches ticket 12 decision 6 (`assigned_church_id` or `church_id`, and `is_priest` or `role = 'priest'`), not `assigned_church_id` alone.
- **"In Mass" depends on ticket 03**: it is true when the priest is the `presiding_priest_id` of a Mass happening now.
- **Status** values: `available`, `in_mass`, `on_leave` (day off and blackout both show as On Leave, with no reason text).

Implementation:
1. Add a "Parish Clergy" section to `ChurchDetailPage.tsx`, hidden when the RPC returns no priests.
2. Clergy card: name with title, designation, status badge, and a "Book with Father" shortcut that opens the existing booking flow for that church. It does not pre-select a priest, since booking has no priest picker (see 05).
3. Light theme tokens per `AGENTS.md`.

Web only. Mobile is ticket 13.

### Files Involved
- `web/src/pages/churches/ChurchDetailPage.tsx`
- `web/src/lib/supabase/profiles.ts` (or a small clergy module wrapping the RPC)
- `web/src/types/database.ts` (regenerated by 12)

## 2. Acceptance Criteria
- [ ] Roster renders for logged-out and logged-in visitors via the RPC only.
- [ ] No leave reason, email or phone is returned or rendered.
- [ ] Status badges show Available, In Mass, On Leave correctly from dashboard leave and Mass schedules.
- [ ] Parishes with no priests show no clergy section.
- [ ] An `admin` account flagged `is_priest` appears in its parish's roster.
- [ ] Local e2e covers anon visitor, on-leave priest and in-mass priest.
- [ ] Builds and passes TypeScript validation cleanly (`tsc -b`).
