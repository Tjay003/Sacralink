# Issue 03: Presiding Priest / Celebrant Liturgy Visibility

Type: feature
Status: ready-for-agent
Blocked by: 12

---

## 1. Description
Parishioners attending Masses or watching livestreams must be able to see who the presiding priest is for a Mass schedule.

`mass_schedules` had no priest column (verified in code and production), so there is nothing to "link" yet. Ticket 12 adds `mass_schedules.presiding_priest_id`. This ticket is the web UI on top of it. The value is a weekly default; it does not model substitutions.

1. `ChurchDetailPage.tsx`: show `Celebrant: Rev. Fr. <name>` as a badge on each Mass schedule card when `presiding_priest_id` is set; show nothing when it is null.
2. `LivestreamPlayer.tsx`: show the celebrant under the broadcast title, live and in the pre-Mass countdown, when the stream's Mass schedule has one. Confirm in code how a stream maps to a Mass schedule before wiring; if there is no link, show the celebrant only where the mapping exists and note the gap in the resolution.
3. `AddScheduleModal.tsx` / `EditScheduleModal.tsx`: add an optional "Presiding priest" select, populated only with that church's priests (same membership rule as ticket 12 decision 6), with a "Not assigned" option. The select is writable only by the roles that can already manage that church's schedules (RLS already restricts `mass_schedules` writes).
4. Priest names are read through the ticket 12 RPC or a joined read that exposes only display name and title.

Web only. Mobile is ticket 13.

## 2. Acceptance Criteria
- [ ] Mass schedule cards show the celebrant badge only when assigned.
- [ ] Livestream player shows the celebrant in live and standby views where a schedule mapping exists.
- [ ] Add and edit modals can assign, change and clear the presiding priest, restricted to that church's priests.
- [ ] Assigning a priest does not break existing schedule add/edit/delete flows or the mobile church screen (column is additive).
- [ ] Local e2e covers assign, change and clear.
- [ ] Builds and passes TypeScript validation cleanly (`tsc -b`).
