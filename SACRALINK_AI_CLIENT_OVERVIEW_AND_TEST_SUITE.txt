1. EXECUTIVE SUMMARY & MISSION
================================================================================
In most Catholic parishes across the Philippines and worldwide, church offices 
are flooded with repetitive inquiries:
- "Father/Ate, ano po requirements sa binyag?"
- "May kumpisal po ba mamaya bago mag-misa?"
- "Pwede po ba magpabinyag kung hindi kasal sa simbahan ang magulang?"
- "Magkano po ang pamisa sa patay at paano mag-GCash?"

Parish secretaries are overwhelmed during weekday office hours, and outside 
office hours (evenings, Mondays, holidays), parishioners are left waiting.

The SacraLink AI Parishioner Assistant solves this bottleneck. It serves as 
a dedicated, 24/7 Digital Parish Receptionist and Catechetical Guide. It is 
grounded strictly in the official canonical records, schedules, and diocesan 
guidelines of each specific parish, answering inquiries instantly with warmth, 
reverence, and factual precision.

================================================================================
1. 24/7 Instant Pastoral Availability:
   Parishioners can inquire at midnight, during commute, or over weekends and 
   receive immediate answers without waiting for parish doors to open.

   Automates 80% to 90% of routine, repetitive inquiries (mass schedules, office

   Eliminates conflicting gossip or outdated paperwork checklists. The AI

   are warmly welcomed for Holy Baptism regardless of their parents' civil status).

4. Stewardship & Cashless Transparency:
   Provides verified GCash, Maya, and bank payment instructions with transparent 
   canonical stipends and financial hardship provisions, boosting church 
   generosity and financial integrity.

5. Multilingual & Taglish Fluency:
   Understands natural Taglish, formal Tagalog, and English, matching the way 
   Filipino parishioners actually speak and type in real life.

================================================================================
* Multi-Platform Availability:
  Accessible via both the SacraLink Web Portal (floating interactive assistant) 
  and the Native Mobile App (iOS / Android floating action button and modal).

  If internet connection flickers or external AI services experience rate limits,

  are NEVER left without an answer.

* Full Audit Logging & Pastoral Oversight:
  Every inquiry and AI response is securely logged in `church_chat_logs`. Parish 
  administrators can review what questions parishioners are asking and identify

* Spiritual Reverence & Liturgical Etiquette:

4. HOW THE AI WORKS: STEP-BY-STEP KNOWLEDGE HANDLING & ARCHITECTURE
================================================================================

Below is the technical workflow illustrating how parish documents are ingested, 
stored, retrieved, and answered in real time:

+-----------------------------------------------------------------------------+
|                            PARISH ADMINISTRATION                            |
|  Parish Secretary updates Mass Times, Requirements, or Knowledge Base in   |
|  the SacraLink Admin Dashboard (/knowledge).                                |
+--------------------------------------┬--------------------------------------+
                                       │
                                       ▼ Click "Sync AI Knowledge Base"
+-----------------------------------------------------------------------------+
|               SUPABASE EDGE FUNCTION: `sync-church-knowledge`               |
|  1. Gathers: Mass schedules, announcements, sacrament requirements, and     |
|     custom knowledge sections (e.g. La Salette Parish Handbook).            |
|  2. Chunks text into semantically cohesive paragraphs.                      |
|  3. Sends chunks to Google Gemini Embedding API (`gemini-embedding-001`).   |
|  4. Produces high-dimensional (768-D) mathematical vector representations.  |
|  5. Upserts vectors & text into Postgres table: `church_knowledge_chunks`.  |
+-----------------------------------------------------------------------------+

                                       │
                                       ▼ Storage Complete
+-----------------------------------------------------------------------------+
|                 SUPABASE POSTGRESQL + PGVECTOR DATABASE                     |
|  Stores chunked text, metadata (source_type, parish_id), and vector vectors |
|  with an indexed Cosine Distance operator for lightning-fast similarity.    |
+-----------------------------------------------------------------------------+

                                       ▲
                                       │ Real-time Similarity Query
+--------------------------------------┴--------------------------------------+
|                     LIVE PARISHIONER QUERY WORKFLOW                         |
|                                                                             |
|  1. Parishioner types query in Web or Mobile app:                           |
|     "Pwede po ba magpabinyag kung hindi kasal sa simbahan ang magulang?"    |
|                                                                             |
|  2. Frontend sends payload { churchId, message, conversationHistory }      |
|     to Supabase Edge Function: `church-ai-chat`.                            |
|                                                                             |
|  3. The Edge Function converts the user's question into a 768-D vector.     |
|                                                                             |
|  4. Vector Search (`match_church_knowledge` RPC):                           |
|     Calculates cosine distance between question vector and parish chunks.   |
|     Retrieves the top 3-5 most relevant verified chunks.                    |
|                                                                             |
|  5. Grounded Prompt Assembly:                                               |
|     Injects retrieved chunks + Church Name + Emergency Numbers into a       |
|     specialized Catholic Pastoral System Instruction.                       |
|                                                                             |
|  6. Gemini LLM Generation (`gemini-2.0-flash` with failover logic):         |
|     Composes a concise, pastoral, highly accurate response.                 |
|                                                                             |
|  7. Client Display & Audit Trail:                                           |
|     Displays markdown response with clickable recommendations, and logs to  |
|     `church_chat_logs` for administrator review.                            |
+-----------------------------------------------------------------------------+

4.1 Knowledge Ingestion & Chunking:
    Parishes can manage their knowledge directly through the SacraLink Web 
    Admin Portal (`/knowledge`). Knowledge is organized into distinct logical 
    sections (e.g., General Information, Mass Schedules, Baptism, Matrimony, 
    Confirmation, Stipends & Donations, Document Requests). When saved, texts 
    are segmented with header context so the AI understands both the topic and 
    the details.

4.2 Vector Embeddings (Gemini 768-D):
    Instead of relying on fragile keyword matching (which fails if someone says 
    "Pamisa" instead of "Mass intention"), vector embeddings translate human 
    meanings into geometric space. "Ninong requirements", "godfather age", and 
    "patakaran sa ninang" all point to the exact same conceptual vector space.

4.3 Grounded Generation (RAG):
    By supplying the verified chunks as direct reference materials in the prompt, 
    the model is strictly instructed:
    "Answer based ONLY on the provided parish context. If an answer cannot be 
    determined from the context, politely direct the parishioner to the parish 
    office and provide the office contact number."

4.4 Failover & Dual-Layer Reliability:
    - AI Layer Failover: If `gemini-2.0-flash-lite` experiences rate limiting, 
      the system automatically retries with `gemini-2.0-flash` and `gemini-2.5-flash`.
    - Local DB Fallback: If edge function communication fails, the client-side 
      app invokes `generateFallbackResponse`, directly querying Postgres tables 
      for live mass schedules and sacrament lists without breaking conversation.

4.5 Audit Logging & Privacy:
    All conversations are recorded in `church_chat_logs` with timestamps, parish ID, 
    and masked user IDs. No private confessional secrets or sensitive financial 
    passwords are ever requested or stored.
